## 参数与用途

- [ ] 具体模型的常规详情页直接显示「思考」分组，无需进入高级设置；初始选择「默认」，服务详情没有全局思考入口。
- [ ] 模型选择「修改」后配置协议对应的强度或预算，保存后检查请求；恢复「默认」时不发送思考字段。Anthropic 手动开启思考需填写至少 1024 的预算。
- [ ] 导入含渠道思考字段的旧文件，看到已忽略提示；验证对象、点路径及渠道 extraBody 中的思考不会影响模型，模型显式思考仍有效，普通渠道参数继续继承。
- [ ] 新渠道的可选参数均未启用，脱敏请求体中不出现 temperature、top_p 等字段。Anthropic 未开启思考时，必需 max_tokens 按显式值、模型输出容量、1024 的顺序取值。
- [ ] Anthropic 手动开启思考并设预算 4096：没有显式输出上限或模型上限时，max_tokens 默认 5120；实际采用的显式上限或模型上限小于等于 4096 时提示调整，较大的有效上限保持原值。预算非整数或小于 1024 时拒绝发送，extraBody 覆盖也遵守同一规则。
- [ ] 渠道启用一个参数，模型依次选择继承、发送自定义值、不发送；核对真实请求体和导出 JSON。
- [ ] 分别输入 `false`、`0`、空数组和嵌套对象，确认值保留原 JSON 类型，不被当作未设置。
- [ ] 为自定义字段选择对象/数组，输入错误类型或无效 JSON，确认不能应用且原值仍在。
- [ ] 检查普通对象参数与点路径并用的继承、覆盖和省略，例如渠道 generationConfig 对象与模型 generationConfig.temperature。
- [ ] 各协议的「兼容选项」从未设置切为覆盖后测试，再取消覆盖；导入的未知扩展字段仍保留。
- [ ] 「我的 → 模型服务 → 解题模型」为截图识题、极速、深度绑定同一模型及不同服务同名模型；长按拖动排序使其成为第一（显示「默认」），垃圾桶移除后「撤销」，重新打开检查顺序。读屏可用「上移 / 下移」操作。
- [ ] 默认项优先，其余项按候选顺序回退；第一项在尚未输出时失败可回退，OCR 已有任何输出后失败不自动向下一项重复发送。

## 解答页临时思考设置

- [ ] 每题解答标题区合并显示模型、状态和思考胶囊；核对标签对应本次编码后的请求参数，未发送思考参数时显示「默认」（语义为服务端默认）。不按模型名称、视觉或思考元数据隐藏选项；题目未识别完成或协议不明时入口不可用。
- [ ] 点击思考入口打开蓝紫渐变滑杆浮层，答案正文位置不变；滑动改变预览层级，但请求和原答案不变。关闭浮层不请求，再次打开恢复实际层级。点击「确认」才仅重试当前题当前模式，其他题和另一模式保持原状；「默认」同样需要确认，不再出现模型/还原按钮。手动预算单独显示一行输入，取消不请求，点击确认才发送。
- [ ] 点击解答标题区的模型入口，菜单同选当前模型不请求；换模型仅重答本题当前模式，并清除旧临时层级。题目标题行右侧「⧉ 题目」复制题目，答案末尾「⧉ 答案」复制解答，旁边是重试。
- [ ] 底部单行的重截、状态、停止／收起位置稳定；停止只终止当前模式及未完成识题，收起调用统一退出流程并取消全部模式。100% 与 130% 字体下按钮、思考胶囊触点至少 48dp，底栏随键盘避让，无假输入框或无功能发送箭头。
- [ ] 模型原本配置了思考时，临时选择「默认」并确认，本次恢复模型原来的强度、预算和摘要/展示等参数，包括 extraBody；不写回持久配置，也不强制清空模型原参数。
- [ ] 显式切换强度或预算时，分别检查 Responses reasoning.summary、Anthropic thinking.display、Gemini includeThoughts 和 Chat Completions thinkingBudgets 档位映射继续生效，普通对象、点路径及 extraBody 均覆盖；旧强度/预算不会反盖新选择，标签反映兼容转换后的实际请求值。
- [ ] 临时选择强度或预算后，普通重试继续使用同一临时值；选择「默认」后恢复模型已保存值。切换到其他模型或开始新截图后，旧临时值不带入新模型/新轮；模型与渠道配置、用途绑定及导出 JSON 均保持原值。
- [ ] OpenAI 两种协议分别选择 none/minimal/low/medium/high/xhigh/max，界面显示关闭/最低/低/中/高/很高/最高，请求使用对应协议原值；Chat Completions 使用兼容格式或显式不支持 reasoning_effort 时，标签以最终编码结果为准，不把已被移除的字段显示为已发送。
- [ ] Anthropic 在 adaptive 强度 low/medium/high/xhigh/max（低/中/高/很高/最高）与 enabled 手动预算之间切换，确认互斥；预算小于 1024、非整数，或有效 max_tokens 小于等于预算时，在面板显示预检错误并保留已有答案及正在运行的请求，不静默提高已设置的输出上限。
- [ ] Gemini 在 MINIMAL/LOW/MEDIUM/HIGH 与预算 -1、0、正整数之间切换，确认思考强度和预算不会同时发送；无效预算不能确认，修正后仅重试本题当前模式。
- [ ] 菜单或预算编辑期间自动回退到另一模型或协议时，关闭旧菜单并丢弃未提交预算，重新打开后的选项属于实际请求模型；已读答案和思考折叠状态不变。
- [ ] 在真实悬浮答案窗选择手动预算，点击输入框后可用软键盘输入，外层遮罩不拦截键盘；收起面板或点击外部关闭答案后键盘和输入焦点释放。键盘显示时重截，收到的截图不含 NoDoubt 的键盘、答案窗或悬浮球，新答案窗仍可继续操作。

## 本地文件与远程配置

- [ ] 「我的 → 模型服务 → 配置文件」新建空白、复制当前、铅笔重命名、轻点切换、垃圾桶删除；确认新建/复制后当前配置正确，各配置集相互独立。
- [ ] 删除当前配置集后切到其他项；最后一个配置集的删除操作不可用。恢复上一个有效版本先确认，恢复后内容可用。
- [ ] 通过「从文件导入」选择应用配置 JSON，先看到差异；取消不改变当前配置，合并与替换分别符合预览。
- [ ] 替换要求额外确认；UTF-8 BOM 文件可读，无效 JSON、未知协议、超过 2 MB 的文件显示可理解的结果或错误，当前有效配置不被静默清空。
- [ ] 「导出配置 → 保存为文件 / 复制到剪贴板」保留服务、模型、用途和应用设置；默认不含真实密钥，剪贴板始终不含密钥；明确开启包含密钥后再验证文件导出，测试后妥善清理文件。
- [ ] 「从剪贴板导入」分别粘贴 JSON 与订阅 URL，确认都先预览。
- [ ] 在新配置集导入无密钥导出文件，补充 API Key 或「变量映射」后才能使用；缺失变量显示修复原因，`!command` 不执行。
- [ ] 「配置文件 → 配置订阅」获取并预览；取消无变化，订阅后显示来源与更新时间。远程未改动时「检查更新」提示已是最新；修改远程后检查更新，确认本地覆盖保留、未本地改动的内容可更新。「停止订阅」保留已导入服务。
- [ ] 远程断网、非 JSON 响应、失效地址与本地配置在预览后改变时，不能静默覆盖有效配置；重新获取后可继续。
