# NoDoubt 全应用重构

已确认范围：Kotlin + Compose；偏 iOS 的手机界面，主题色为海蓝（默认）、暖橙、石墨，支持明暗与跟随系统；模块化；普通 Kotlin 文件目标 150–300 行，超过 400 行检查拆分；保留截图识题、极速/深度回答、候选模型回退、Markdown/公式、悬浮答案和个人设置。

协议限定为 openai-completions、openai-responses、anthropic-messages、google-generative-ai。仅 API 配置，无订阅登录。取消依据模型名称或目录能力标记对模型选择的限制。可选参数默认不发送，必需字段显式标注；普通模型参数可继承/覆盖/省略渠道设置，持久思考配置仅属于具体模型，解答页可临时覆盖当前题、当前模式的请求设置，服务返回的思考内容直接展示。

配置采用 providers + nodoubt 扩展，支持 GUI、应用配置文件导入导出、本地配置集管理、远程导入与更新差异预览、秘密引用与旧配置迁移。远程更新保留本地覆盖，导入不执行命令。配置与协议参考仅限技术结构，应用使用路径保持独立。

## 架构

app 负责装配和导航；core:model 保存共享契约；core:config 负责版本化存储、凭据、迁移与导入；core:ai 负责独立协议适配；core:designsystem 负责主题和通用界面；feature:channels 负责渠道配置；feature:solver 负责题目状态和回答；platform 负责截图和窗口。

## 页面目标

主导航为「首页 / 我的」。首页控制悬浮球；「我的 → 模型服务」管理服务与模型，并进入「解题模型」和「配置文件」；外观、阅读和截图设置也从「我的」进入。持久思考配置在具体模型的常规详情页使用「默认 / 修改」，默认不发送思考参数。解答标题区合并显示模型、状态和本次思考设置，点击小胶囊打开紧凑浮层，滑动预览层级，确认后才重试当前题、当前模式；关闭丢弃草稿，手动预算仅用一行输入与确认/取消，不撑开大块面板；「默认」恢复模型原有思考参数，不再提供单独的模型/还原按钮，显式强度/预算切换保留摘要、展示偏好和档位预算映射。两处入口使用同一协议目录，档位中文显示最低、低、中、高、很高、最高等名称。临时选择不写入模型、渠道或配置 JSON；普通重试沿用，切换模型或新截图后恢复模型设置。

答案使用全宽贴底抽屉，初始高度约为屏幕的三分之二，顶部把手可上下调整高度。所有题目在当前模式的同一页面连续排列；顶部选项或左右滑动切换极速解题与深度思考。底部固定重截和状态，运行时提供停止，其余状态提供收起；模型切换位于每题解答标题区，每题完成后在答案末尾提供复制和重试。停止按钮终止当前模式及未完成的识题；退出或收起解题页立即取消 OCR、极速、深度全部请求。快速重截先取消旧轮全部请求，隐藏自身悬浮窗口后再截图，拦截重复点击并丢弃旧轮迟到结果。

题目使用灰底区域，解答正文保持独立层级。两种模式收到思考内容后均显示默认展开、可折叠的思考区，不依赖请求是否启用了思考参数。初始等待、识题和排队保持对应状态；用户实际中止任务才显示已停止，重截的内部清理不发布停止状态。

## 验证目标

- 旧主分支、default_channel 中间格式、channels_json 版本迁移；原始数据保留，失败不得覆盖有效配置。
- 四协议请求格式、图片、流分片、推理事件、错误与取消；未启用字段不发送。
- 模型继承/覆盖/省略、详情页思考设置、应用配置导入导出、配置合并与远程刷新。
- 多题 OCR、双模式返回思考展示、等待/识题/排队与停止状态、退出/收起取消全部请求、快速重截过渡与重复点击、旧轮结果不污染新任务、OCR 有输出后不自动重发、服务与截图权限恢复。
- 构建、单元测试、静态检查、文件行数；具备设备时验证深浅色、大字体、贴底抽屉高度、多题同页和模式滑动。
