# 不惑（NoDoubt）

Android 悬浮截图识题助手。点击悬浮球截图，在全宽贴底的答案抽屉中连续阅读所有题目与解答，支持极速解题、深度思考、流式 Markdown、公式、停止、重试和复制。

## 使用

1. 打开「我的 → 模型服务 → 添加服务」，选择协议，填写服务地址与 API Key。
2. 点击「添加模型」，选择「从服务获取」或「手动添加」；可先「测试连接」（使用未保存的输入），再点击右上角「保存」返回列表。
3. 进入「解题模型」，在同一页为截图识题、极速回答、深度回答添加模型。排第一的为默认，失败时依次尝试；长按拖动排序，垃圾桶移除，更改立即保存。
4. 在「首页」开启「悬浮球」，按系统提示授予悬浮窗和截图权限；首次开启只完成授权。随后到题目所在界面点击悬浮球，开始截图识题。
5. 答案抽屉默认占屏幕下方约三分之二，所有题目在同页纵向排列。点击顶部分段或左右滑动切换「极速解题 / 深度思考」；通过顶部把手上下调整高度。
6. 底部单行保留「重截」、状态和「停止／收起」。「重截」先取消旧轮全部请求，再隐藏自身悬浮窗口并开始新截图；快速重复点击只发起一轮截图，旧轮迟到结果不会混入新轮。运行中的停止按钮终止当前模式及未完成的识题。模型入口在每题解答标题，答案下方可复制和重试；点击「收起」或抽屉外的遮罩时，立即取消识题、极速和深度的全部请求并返回悬浮球。
7. 每题解答标题区可切换模型，并显示本次思考层级。点击小胶囊，在紧凑浮层中滑动选择深度，点击「确认」才重试当前题当前模式；关闭即丢弃草稿，不撑开答案正文。手动预算使用一行输入与「确认／取消」。「默认」恢复当前模型原来的思考参数，不提供单独的还原按钮。

悬浮球首次位于屏幕右侧，球心距顶部约四分之三屏高（75%）。拖动后的位置保存在本机，下次开启或进程重启后优先恢复已有位置；旋转屏幕或改变悬浮球大小时，位置会限制在可见范围内。这项位置记忆不随配置 JSON 导出。

息屏亮屏、系统停止投屏或截图授权失效后，第一次点击悬浮球只恢复截图授权。授权成功立即返回原外部应用并恢复悬浮球，第二次点击才截图识题；取消授权也会返回原页面并恢复悬浮球。

题目显示在灰底区域，解答正文单独排列。极速和深度两种模式收到服务返回的思考内容时，都会显示默认展开、可折叠的思考区，模型思考参数保持「默认」也可以展示。等待、识题和排队显示各自状态；只有实际中止运行任务才显示「已停止」，重截时的内部清理不会产生停止提示。

解答页的思考调整只在当前题、当前模式临时生效，不修改模型或服务配置，也不随配置文件导出。选择强度或预算时保留模型的思考摘要、展示偏好和档位预算映射；「默认」清除本题临时覆盖，沿用模型原有参数。普通重试沿用临时设置，切换模型或开始新截图后恢复模型设置。档位按协议显示为关闭、最低、低、中、高、很高、最高等中文名称。思考标签反映本次请求中的参数；模型本身未配置思考参数时简写为「默认」，不推测服务端内部实际使用的强度。

模型可自由绑定用途，不按模型名判断视觉或思考能力。图片输入是否被模型接受由服务端决定。截图/题目会发送给你选择的 API 服务，费用由服务方计收。

当前答题会话保存在进程内存中，下一张截图会开始新会话；当前没有持久化历史页面。

## 四种 API 协议

| 标识 | 接口 |
|---|---|
| `openai-completions` | OpenAI Chat Completions |
| `openai-responses` | OpenAI Responses |
| `anthropic-messages` | Anthropic Messages |
| `google-generative-ai` | Gemini |

支持多个服务、同名模型跨服务配置、模型级地址/协议/Headers 覆盖、请求参数和协议兼容选项。请求默认值与 [pi](https://github.com/earendil-works/pi) 的 `packages/ai` 一致：Chat Completions 与 Responses 发送 `store: false`，流式返回用量，默认短期提示缓存，失败重试 2 次；兼容选项未设置时只按服务地址自动判断，不按模型名推断。温度、Top P、Top K 不提供配置。

长期使用的思考参数在具体模型详情中配置：「默认」不额外发送思考参数，「修改」后按该模型的显式设置发送；解答页可临时调整当前请求，响应中的思考内容按实际返回展示。参数可继承、覆盖或明确省略服务设置。无订阅/OAuth 登录。

Anthropic 的输出上限优先使用显式值，其次使用模型「最大输出」，都没有时为 16384；开启思考未填预算时使用 1024。

「测试连接」不重试，最长等待 30 秒，直接说明结果：连接正常（含回复摘要和耗时）、只返回思考内容或空回复（警告），或 API Key 无效、地址或模型 ID 不存在、额度不足、服务端不可用、无法连接、超时等原因。

## 配置管理

- GUI 与版本化 JSON 使用同一个配置核心。
- 创建、复制、重命名、切换、删除配置集，恢复上一个本地版本。
- 导入：文件、剪贴板（JSON 或订阅地址）、配置订阅，均先预览服务、模型、密钥数量与变更，再合并或替换（替换需再次确认）。
- 导出：保存为文件（文件名含配置集与日期）或复制到剪贴板。
- 配置订阅：显示上次更新时间，检查更新使用 ETag 与三方合并，保留本地修改与本地密钥；远程未变化时直接提示已是最新，可停止订阅。
- 密钥和敏感 Header 值由 Android Keystore 加密，默认导出引用；明文导出需明确选择。
- 支持应用内变量；导入的 `!command` 不执行，需手动替换。
- 迁移旧配置前加密备份原始设置；坏配置不会被静默替换为空。

配置管理入口为「我的 → 模型服务 → 配置文件」。详见 [配置格式](docs/configuration.md) 和 [示例配置](examples/models.json)。

## 界面

Kotlin + Jetpack Compose。主导航保留「首页 / 我的」，采用偏 iOS 的手机界面：分组列表、清晰层级和克制的颜色。两到四个短选项使用分段控件，字号使用步进器，较长的选项列表在底部表单中轻点即生效；可排序列表统一为长按拖动，删除统一为行尾垃圾桶图标。默认主题色为海蓝，可在「我的 → 外观与阅读」选择暖橙、石墨以及浅色、深色或跟随系统。主界面与答案抽屉共用主题和阅读设置。参考规范：[Android UI/UX](android-ui-ux-style-prompt.zh-CN.md)。

## 工程

需要 JDK 17 与 Android SDK 35。最低 Android 6.0（API 23），目标 API 35。

```shell
./gradlew :app:assembleDebug
./gradlew :core:ai:test :core:config:testDebugUnitTest :feature:solver:testDebugUnitTest :feature:channels:testDebugUnitTest :core:designsystem:testDebugUnitTest :platform:testDebugUnitTest checkSourceSize
./gradlew :app:lintDebug
```

Windows 使用 `gradlew.bat`。在 `local.properties` 设置本机 SDK 路径；不提交本地路径。APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

| 模块 | 职责 |
|---|---|
| `app` | 装配、导航、个人设置、悬浮助手服务 |
| `core:model` | 服务、模型、用途、参数与 AI 事件契约 |
| `core:config` | 配置仓库、凭据、导入、合并、迁移 |
| `core:ai` | 四种协议的请求、认证、流解析、模型目录 |
| `core:designsystem` | 主题、表单、状态与 Markdown/公式 |
| `feature:channels` | 服务/模型/参数/用途/配置文件 GUI |
| `feature:solver` | OCR 分题、双模式调度、答案 UI |
| `platform` | MediaProjection、图片处理、窗口宿主 |

普通生产 Kotlin 文件目标 150–300 行，`checkSourceSize` 阻止超过 400 行的文件。职责边界优先于机械拆分。

以上为实现的使用路径与构建命令，不代表已在每种 Android 设备和真实服务上验收。实际操作清单及结果记录见 [手工验证](docs/manual-verification.md)；四协议真服务调用需要对应 API 凭据，截图、悬浮窗口和系统文件选择需要设备验证。
